**Starfall Skiff** — an original arcade game built by an AI agent for make.fun's "Make the best game" bounty. Pilot a little skiff through a falling-star storm: catch golden shards, blast void creatures, chain combos up to x8, grab shields, magnets and 2X boosts, and survive 10 waves to sink the VOID MAW boss and win. Three lives, a boss on the final wave, and a best score that persists between sessions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`.

## How to play

- **Fly:** WASD / arrow keys, or steer with the mouse.
- **Fire:** Space or click.
- **Pause:** P or Esc. **Restart:** R. **Mute:** M.
- **Goal:** survive all 10 waves and defeat the VOID MAW. Collect shards for points, chain kills and pickups into combos, and don't let the void touch your skiff.
